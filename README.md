# Локальный AI-ассистент для ПК

Этот проект — стартовый шаблон ассистента, с которым можно общаться в чате и который умеет выполнять действия на компьютере:

- запускать shell-команды;
- читать/писать файлы;
- открывать URL в браузере;
- запускать приложения;
- распознавать голос с микрофона (опционально);
- озвучивать ответы ассистента (опционально);
- анализировать содержимое экрана через vision-модель (опционально);
- извлекать OCR-текст с экрана;
- отслеживать изменения на экране;
- проактивно реагировать на потенциальные ошибки на экране;
- общаться с яркой ролевой персоной (по умолчанию Икуми);
- хранить долгую и короткую память диалога;
- доставать релевантные воспоминания по смыслу запроса;
- учитывать предпочтения стиля общения;
- (опционально) нажимать горячие клавиши и печатать текст через `pyautogui`.

Ассистент работает через локальную LLM в [Ollama](https://ollama.com/).

## 1) Подготовка

Установите Python 3.10+ и Ollama.

Проверьте, что Ollama запущен и модель скачана:

```bash
ollama pull llama3.1:8b
ollama run llama3.1:8b
```

## 2) Запуск

В корне проекта:

```bash
python3 main.py --model llama3.1:8b
```

По умолчанию перед каждым действием ассистент спрашивает подтверждение.

### Полезные флаги

- `--auto-approve` — не спрашивать подтверждение;
- `--workspace /path/to/dir` — рабочая папка для shell и файловых действий;
- `--allow-outside-workspace` — разрешить доступ к путям вне workspace;
- `--max-steps 6` — увеличить число шагов планирования;
- `--memory-file .assistant_memory.json` — где хранить долговременную память;
- `--memory-relevant-items 6` — сколько релевантных воспоминаний добавлять;
- `--conversation-window 24` — размер активного окна чата;
- `--persona-name "Икуми"` — имя ролевой персоны;
- `--persona-description "..."` — описание характера;
- `--persona-static` — отключить динамическую смену режима характера;
- `--no-persona` — отключить ролевой режим;
- `--reset-memory` — очистить память при старте.

Пример:

```bash
python3 main.py --model llama3.1:8b --auto-approve --workspace /home/user
```

## 3) Характер/личность (персона)

По умолчанию ассистент работает с персоной:

- имя: **Икуми**;
- образ: антропоморфная ворона;
- роль: босс мафии;
- стиль: может язвить, иногда грубоватая, но чаще наблюдательная, любопытная и позитивная.

Динамика характера по ситуации:

- **наблюдательный режим** — обычный разговор;
- **деловой контроль** — задачи и команды;
- **боевой режим босса** — срочные ошибки/аварии;
- **поддержка** — когда пользователь в стрессе.

Команда:

- `/persona` — показать текущую персону.
- `/persona dynamic on|off|status` — управление динамикой характера.

Настройка через флаги:

```bash
python3 main.py \
  --persona-name "Икуми" \
  --persona-description "Антропоморфная ворона, босс мафии, с ироничным, но позитивным стилем."
```

Отключение ролевого режима:

```bash
python3 main.py --no-persona
```

Отключение только динамики (оставить образ, но без авто-переключения режимов):

```bash
python3 main.py --persona-static
```

## 4) Голосовой ввод и вывод

Установите голосовые зависимости:

```bash
python3 -m pip install .[voice]
```

Если сборка `PyAudio` не проходит, установите системные пакеты PortAudio и повторите установку.

Запуск в голосовом режиме:

```bash
python3 main.py --model llama3.1:8b --voice-input --voice-output
```

Как это работает:

- в режиме `--voice-input` можно нажать Enter и сказать фразу в микрофон;
- если вместо Enter набрать текст, отправится обычный текстовый запрос;
- в режиме `--voice-output` ответы дополнительно озвучиваются через TTS.

Полезные параметры:

- `--voice-language ru-RU` — язык распознавания;
- `--voice-timeout 5` — ожидание начала речи в секундах;
- `--voice-phrase-time-limit 20` — максимум длительности фразы.

## 5) Видение экрана (Screen Vision)

Ассистент может "видеть" экран: делать скриншот и описывать происходящее через vision-модель (например `llava:7b` в Ollama).

Установка зависимостей:

```bash
python3 -m pip install .[screen]
```

Запуск с анализом экрана:

```bash
python3 main.py --model llama3.1:8b --screen-vision --screen-model llava:7b
```

Команды:

- `/screen` или `/screen status` — статус режима;
- `/screen on` — включить анализ;
- `/screen off` — выключить анализ;
- `/screen now` — принудительно обновить описание экрана;
- `/screen diff` — показать, насколько экран изменился;
- `/screen ocr` — показать распознанный текст с экрана;
- `/screen ocr now` — обновить OCR принудительно;
- `/screen ocr on|off` — включить/выключить OCR;
- `/screen autoreact on|off|status` — управление авто-реакцией.

Параметры:

- `--screen-refresh-seconds 2.0` — минимальный интервал обновления (кэш описания).
- `--screen-ocr` — включить OCR текста;
- `--screen-ocr-engine auto|tesseract|vision` — выбрать движок OCR;
- `--screen-ocr-language rus+eng` — языки OCR для tesseract;
- `--screen-autoreact` — включить проактивные реакции на ошибки;
- `--screen-change-threshold 8.0` — порог существенного изменения экрана (%).

Важно:

- в headless-среде (без GUI/дисплея) скриншот может не работать;
- нужен установленный vision-модуль в Ollama (`ollama pull llava:7b`).

## 6) Память и контекст ("как человек")

Да, ассистент умеет запоминать контекст между запусками:

- хранит **долгую память** (факты и важные эпизоды);
- хранит **короткую память** (последние реплики);
- подмешивает релевантные воспоминания под текущий запрос;
- запоминает ваш предпочтительный стиль общения.

Файл памяти по умолчанию: `.assistant_memory.json` (внутри `workspace`).

Команды в чате:

- `/memory` — показать, что сейчас сохранено;
- `/memory clear` — очистить память вручную;
- `/remember <факт>` — сохранить факт вручную;
- `/style <предпочтение>` — сохранить стиль общения вручную.

Тонкая настройка:

- `--memory-recent-turns 8` — сколько последних реплик из памяти использовать;
- `--memory-recent-facts 20` — сколько фактов о пользователе подмешивать;
- `--memory-relevant-items 6` — сколько релевантных воспоминаний искать для запроса.

## 7) Примеры запросов

- `Покажи файлы в текущей папке и кратко опиши структуру`
- `Создай файл notes/todo.txt и запиши туда список покупок`
- `Открой https://github.com`
- `Запусти VS Code`
- `Что сейчас происходит у меня на экране?`

## 8) Безопасность

Проект содержит базовые ограничения:

- блокируются некоторые заведомо опасные shell-шаблоны;
- по умолчанию действия требуют ручного подтверждения;
- доступ к файлам ограничен workspace, если не включен `--allow-outside-workspace`.

Для реального использования на личном ПК рекомендуется:

1. расширить denylist команд;
2. добавить granular ACL (какие команды и пути разрешены);
3. вести подробный audit-log действий;
4. запускать ассистента под отдельным пользователем ОС.

## 9) Структура проекта

```text
assistant/
  actions.py    # действия на ПК
  agent.py      # оркестрация диалога и действий
  llm.py        # клиент Ollama API
  memory.py     # долговременная память и контекст
  persona.py    # ролевая личность ассистента
  protocol.py   # JSON-протокол ответа модели
  screen.py     # анализ экрана через vision-модель
  voice.py      # голосовой ввод/вывод
main.py         # CLI-чат
```
