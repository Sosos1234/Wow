# Локальный AI-ассистент для ПК

Этот проект — стартовый шаблон ассистента, с которым можно общаться в чате и который умеет выполнять действия на компьютере:

- запускать shell-команды;
- читать/писать файлы;
- открывать URL в браузере;
- запускать приложения;
- распознавать голос с микрофона (опционально);
- озвучивать ответы ассистента (опционально);
- (опционально) нажимать горячие клавиши и печатать текст через `pyautogui`.

Ассистент работает через локальную LLM в [Ollama](https://ollama.com/).

## 1) Подготовка

Установите Python 3.10+ и Ollama.

Проверьте, что Ollama запущен и модель скачана:

```bash
ollama pull llama3.1:8b
ollama run llama3.1:8b
```

## 2) Запуск

В корне проекта:

```bash
python3 main.py --model llama3.1:8b
```

По умолчанию перед каждым действием ассистент спрашивает подтверждение.

### Полезные флаги

- `--auto-approve` — не спрашивать подтверждение;
- `--workspace /path/to/dir` — рабочая папка для shell и файловых действий;
- `--allow-outside-workspace` — разрешить доступ к путям вне workspace;
- `--max-steps 6` — увеличить число шагов планирования.

Пример:

```bash
python3 main.py --model llama3.1:8b --auto-approve --workspace /home/user
```

## 3) Голосовой ввод и вывод

Установите голосовые зависимости:

```bash
python3 -m pip install .[voice]
```

Если сборка `PyAudio` не проходит, установите системные пакеты PortAudio и повторите установку.

Запуск в голосовом режиме:

```bash
python3 main.py --model llama3.1:8b --voice-input --voice-output
```

Как это работает:

- в режиме `--voice-input` можно нажать Enter и сказать фразу в микрофон;
- если вместо Enter набрать текст, отправится обычный текстовый запрос;
- в режиме `--voice-output` ответы дополнительно озвучиваются через TTS.

Полезные параметры:

- `--voice-language ru-RU` — язык распознавания;
- `--voice-timeout 5` — ожидание начала речи в секундах;
- `--voice-phrase-time-limit 20` — максимум длительности фразы.

## 4) Примеры запросов

- `Открой https://github.com`

## 5) Безопасность

Проект содержит базовые ограничения:

- блокируются некоторые заведомо опасные shell-шаблоны;
- по умолчанию действия требуют ручного подтверждения;
- доступ к файлам ограничен workspace, если не включен `--allow-outside-workspace`.

Для реального использования на личном ПК рекомендуется:

1. расширить denylist команд;
2. добавить granular ACL (какие команды и пути разрешены);
3. вести подробный audit-log действий;
4. запускать ассистента под отдельным пользователем ОС.

## 6) Структура проекта

```text
assistant/
  actions.py    # действия на ПК
  agent.py      # оркестрация диалога и действий
  llm.py        # клиент Ollama API
  protocol.py   # JSON-протокол ответа модели
  voice.py      # голосовой ввод/вывод
main.py         # CLI-чат
```
